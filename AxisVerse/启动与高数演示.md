# AxisVerse 启动与高数演示

## 从 GitHub 获取后启动（Windows）

环境要求：Node.js 24、pnpm 11、Python 3.12 或以上；首次安装需要联网。扫描件 OCR 依赖 Windows 中文 OCR 组件，文本版教材不需要 OCR。

进入 AxisVerse 目录，复制 `.env.example` 为 `.env`，填写 `DEEPSEEK_API_KEY`（模型 Key）与 `AXISVERSE_MCP_KEY`（SH 资料服务 Key）。两者不是同一个凭据；也可沿用已有 `axisverse-course-mcp.local.json` 资料连接文件。密钥只保存在本地，不提交 GitHub。

```powershell
git clone https://github.com/246706510miao-svg/ai-education-material-library.git
cd ai-education-material-library/AxisVerse
Copy-Item .env.example .env
# 用本机编辑器填写 .env；不要把密钥粘贴到聊天或录屏中。
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/axisverse.ps1
```

脚本自动安装 Node/Python 依赖、完成首次构建并通过 dsh 启动 Web。打开启动日志给出的本机地址；如包含登录参数，使用完整地址。后续可直接运行 `pnpm run axisverse:start`。修改源码后使用启动脚本的 `-Rebuild` 参数。首次安装和构建不是即时完成；录制可剪辑等待。

## 演示材料

本机已准备 `资料/演示/高等数学学习教材.pdf`，录制时只上传这一份。它是原《高等数学》第八版下册 PDF 的相同内容副本。其他机器需自行准备这份教材。保留原文件内容和真实版本；展示名称可简化为“高等数学学习教材.pdf”。无需将教材或真题 PDF 上传 GitHub。

共享资料已为南京理工大学软件工程专业准备 2023 年高等数学 II 试卷的人工核对题目索引，以及第六题的教学补充推导。索引来自用户试卷，补充推导不是官方答案。本次只有一份明确的下册试卷，不能宣称跨年份高频统计。

## 演示顺序与可直接粘贴的输入

1. 上传教材，等待界面显示处理完成。
2. 新建“讲义学习”会话，在普通输入框先把上传教材的资料链接加入提问，粘贴以下问题，不选择“仅根据单份资料”模式。

> 我是南京理工大学软件工程专业的学生，刚上传了高等数学下册教材，但不知道应该重点复习哪些内容。请主动检索我上传的教材，以及共享资料中的2023年高等数学II试卷题目索引。用表格列出重点模块、试卷考查依据和学习建议，再给出三个阶段的学习目标。重点说明重积分模块，回答控制在600字以内，并标注资料来源。请实际查阅资料后回答。

3. 在同一会话继续提问。

> 请讲解2023年高等数学II试卷第六题：计算三重积分 ∭Ω (x+z)dV，其中Ω为曲面 z=√(x²+y²) 与 z=2 所围的闭区域。先检索这道题的共享资料和教学补充推导，再查阅上传教材中的三重积分方法。按“理解区域—选择坐标—确定积分限—计算—易错点”讲解，说明为什么x项积分为零，以及体积元为什么要乘r。请调用绘图工具画出xOy平面上的投影圆盘x²+y²≤4，明确标注这是二维投影。补充推导不是官方解析，请据实注明。最后给一道只改变上界高度的练习，先不给答案。

4. 展示互动反馈。

> 如果把上界改成z=3，我算得81π/4，是否正确？请检查我的结果，并总结这类圆锥区域积分题的三个关键步骤。

第六题结果为4π；上界改成3时为81π/4。模型措辞可能变化，演示以实际生成结果为准。

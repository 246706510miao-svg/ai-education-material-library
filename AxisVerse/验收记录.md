## 发现并修复的问题

1. 启动混用源码与构建模块，导致工具运行时对象不一致：改为构建后的正式 dsh CLI。
2. 旧 team patch 覆盖上传配置：移除多余覆盖，清空依赖旧机器回执的默认项。
3. 上游目录未转发学校、专业及类型筛选：接口补齐筛选参数。
4. 相同文件全库去重误复用其他专业文档：按学校、专业、课程及资料类型去重，客户端幂等键也带资料范围。
5. 远程检索的旧默认专业排除软件工程教材：预设明确要求每次搜索传 school 与 major。
6. PDF 文本解析丢失数学上标：演示索引用可检索幂次记法重新入库；旧索引保留原件并标记不可检索。
7. Windows CRLF 导致生成 JavaScript 字符串非法：目录生成器补齐回车转义并增加回归验证。
8. `.env` 中资料 Key 更新未覆盖默认连接：修复凭据轮换并增加测试。
9. 学习记录导出函数缺少返回类型、归档脚本假定项目位于 Git 根目录：补齐类型，改为基于工作目录读取 Git 基线；回归与类型检查通过。
10. 文档测试重复遍历导致超时，Windows 文件符号链接依赖权限：合并遍历（仍检查原 692 份 README），改用目录 junction 保留越界读取拒绝断言；完整相关测试通过。

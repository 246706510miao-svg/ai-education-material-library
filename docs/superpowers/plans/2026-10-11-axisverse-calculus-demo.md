# AxisVerse 高数演示交付实施计划

**目标：** 从 GitHub 获取 AxisVerse 源码，配置模型及资料服务 Key，启动后上传高数教材，联合 SH 的指定真题进行重点总结、阶段目标安排和题目讲解。取消马原及外部智能体演示。

**方案：** 保留现有 dsh Web、PDF 上传和远程 MCP 架构；使用软件工程专业配置及独立高数演示预设，明确教材与真题联合检索规则。启动脚本统一生成本地配置，不向 Git 提交凭据、上传教材或运行记录。

**约束：** 学校为南京理工大学，专业为软件工程；资料源为项目资料目录。教材上传以真实入库成功为准，讲解引用真实切片，不伪造检索。不同学期真题不得混用于重点频次结论。共享资料不声称为个人隔离存储。应用只通过 dsh profile 启动。

- [ ] 核对 SH 接口、资料目录、教材版本与各试卷适用学期。
- [ ] 建立文档/题目/页码及目标切片清单，选定高数下册演示题。
- [ ] 恢复依赖与 Python 环境，构建现有项目，记录环境阻塞。
- [ ] 编写配置/启动入口的行为测试：空 Key 拒绝、凭据不覆盖、干净目录配置和正确 profile 参数。
- [ ] 实现统一配置及启动入口，配置学校专业和共享真题范围。
- [ ] 调整预设：自动识别资料教学需求，允许教材与指定真题联合检索，逐卷读取后总结，后续题目重新核对解析和教材；保留仅限单文档提问。
- [ ] 上传/核验 SH 真题及指定切片，记录文档 ID 和证据，不上传密钥至公开工件。
- [ ] 使用全新目录验证安装、配置、启动、教材上传、重点总结及讲题；没有模型 Key 则明确记录真实问答尚未验收。
- [ ] 更新仅高数视频文稿、启动说明和验收记录。

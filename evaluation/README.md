# Retrieval evaluation

`sample.jsonl` only validates the data contract and metric code. It is synthetic and is not evidence that retrieval is effective.

Real effect evaluation still requires 3–5 representative PDFs, 30–50 Chinese questions with document/page labels, and 5–10 deliberately unanswerable questions. Report Top-1, Top-5, MRR, no-answer precision/recall, p50/p95 latency, exact model ID and corpus revision.
